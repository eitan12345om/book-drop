# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub instead: go to the [Security tab](https://github.com/eitan12345om/book-drop/security) and click **Report a vulnerability**. Include steps to reproduce and, if you can, the impact you expect.

You should get a reply within a week. Once a fix is released, you'll be credited in the advisory unless you'd rather stay anonymous.

## Supported versions

Only the latest commit on `main` (what runs at [bookdrop.cc](https://bookdrop.cc)) receives security fixes. If you self-host, please keep up to date with `main`.
